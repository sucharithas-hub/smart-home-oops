# Smart Home Automation System (Python OOP Assessment)

## Overview
A Python command-line project built to demonstrate Object-Oriented Programming (OOP) principles using a real-world Smart Home device paradigm.

## OOP Concepts Implemented
1. **Classes and Objects:** Reusable blueprints (`SmartDevice`, `SmartLight`, `SmartThermostat`) and instantiated devices.
2. **Inheritance:** Subclasses inheriting core power and status functions from a parent base class.
3. **Polymorphism / Method Overriding:** Customized `status()` method handling specific attributes for smart lights.
